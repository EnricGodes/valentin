# Guías de modelo Porsche: traducciones

Este paquete contiene las 18 guías completas en inglés (`en`), catalán (`ca`), italiano (`it`), alemán (`de`) y francés (`fr`). Cada JSON contiene las mismas 18 guías, en el mismo orden que el original castellano.

El formato sigue siendo `valentinmotors-guias-v1`. Se han conservado la estructura, las claves del importador, los slugs, las referencias a tarifas y los enlaces a artículos y servicios. No se añade ningún campo de idioma: la versión se identifica por el sufijo del archivo.

Las cifras y designaciones se conservan tal como aparecen en el original, incluidas sus comas y puntos. Los títulos SEO tienen un máximo de 70 caracteres y las descripciones, entre 120 y 160. La marca mantiene la grafía Valentín Motors.

Para importar, seleccione el JSON correspondiente a cada idioma y utilice el circuito habitual del sitio. El paquete incluye un informe de validación estructural y de metadatos.
